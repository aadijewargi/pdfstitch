Stitch PDFs together.

Drop in files, put them in order, choose the pages you want, and download one PDF. It all happens in this tab. Your files are never uploaded anywhere.

Source and command-line version on GitHub

Files

    Drag a file to move it, or use its up and down buttons.

    Your merged PDF

    Add at least one file to start.

    How to choose pages
    1-3,7
    pages 1 to 3, then 7
    4-
    page 4 to the end
    end-1
    all pages, last to first
    odd, even
    every other page
    2,2
    repeat a page

    Leave the box empty to take every page.

    Prefer the command line? pip install git+https://github.com/aadijewargi/pdfstitch, then pdfstitch a.pdf b.pdf:2-5 -o out.pdf. It also handles password-protected files.
